# Nullify

Stops click hijacking, for AI browser agents and for people: invisible layers that steal clicks, pop-ups and redirects you didn't ask for, and hidden instructions aimed at AI agents.

- **Code, install instructions and results:** [github.com/Aryavvij/nullify](https://github.com/Aryavvij/nullify)
- **Demo (66 s):** [nullify-demo.mp4](demo/nullify-demo.mp4)
- **Chrome extension download:** [latest release](https://github.com/Aryavvij/nullify/releases/latest)
- **See it work:** [test pages](try/), harmless pages that hijack clicks the way ad sites do
- **Privacy policy:** [store/PRIVACY](store/PRIVACY.html)

For AI agents: `npm install @nullifyads/agent-guard` · `pip install nullify-guard` · `claude mcp add nullify -- npx -y @nullifyads/mcp`
